## المبادئ التنفيذية لجمع البيانات:
1. **الجمع المشروط بالقبول**: لا يتم إرسال أي إشارات سلوكية أو أحداث تتبع ما لم تكن قيمة `consent_flag = true`.
2. **المراجعة البشرية الإلزامية**: كل رسالة عرض تسويقي مولّدة بالذكاء الاصطناعي تخضع لمراجعة الموافقة البشرية الصريحة قبل الإرسال البريدي عبر SendGrid / SMTP.
3. **التشفير وحفظ البيانات**: جميع السجلات تُحفظ مشفرة ببصمة SHA-256 ومرتبطة بـ Reviewer ID المعين.
